## Practical Scenario: Create a Web Platform

A Vida Cristã produz revistas vendidas em um modelo por Assinatura.

- A Editora envia as revistas produzidas para UIECB, que é responsáve por distribuir para as Associações

- Em cada Associação (em regra) há uma Supervisora responsável por receber as revistas, vender e enviar os comprovantes de pagamento para CONFEUAF.

### Problemas identificados

- A Supervisora está mandando as pessoas enviarem o pagamento diretamente para a conta da UIECB, inviabilizando a identificação de quem pagou ou não.

- A Supervisora não está repassando a informação de quem pagou diretamente a ela, apenas faz o repasse dos valores, inviabilizando auditar se Númer de Pagamentos = Número de Exemplares vendidos.

### Objetivo

Criar um MVP para apresentação ao cliente, utilizando PIX como forma de pagamento.
